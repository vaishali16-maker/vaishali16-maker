## 🚀 Projects

- **[Scholar-Research-Agent](https://github.com/vaishali16-maker/Scholar-Research-Agent)** — 
  AI research agent (built for the SerpApi India Hackathon) that turns a 
  topic into a citation-grounded research brief, then cross-checks the 
  literature's open gaps against Google Patents to flag ideas that are 
  unexplored both academically and commercially. FastAPI + Groq + SerpApi 
  (Scholar & Patents engines).
- **[AI-RAG-chatbot](https://github.com/vaishali16-maker/AI-RAG-chatbot)** — 
  RAG chatbot that answers questions from uploaded sales PDFs. FastAPI + 
  LangChain (LangGraph router/retrieve/generate) + Groq + Supabase vector 
  retrieval.
- **[AI-Guardian-review-bot](https://github.com/vaishali16-maker/AI-Guardian-review-bot)** — 
  GitHub App that reviews pull requests automatically via webhook, powered 
  by Groq. Async queue, retry/backoff, CI via GitHub Actions, branch 
  protection.
- **[Ticket-analytics-agent](https://github.com/vaishali16-maker/Ticket-analytics-agent)** — 
  NL-to-SQL agent over IT support ticket data, plus a fine-tuned 
  DistilBERT+LoRA classifier predicting SLA breach risk. Dockerized, 
  deployed on Render & Streamlit Cloud.
- **[Hackathon-buy-or-wait-Hackerrank](https://github.com/vaishali16-maker/Hackathon-buy-or-wait-Hackerrank)** — 
  AI agent for the HackerRank Orchestrate "Buy or Wait?" challenge — decides 
  expense affordability (payment plan, timing, spending changes) from 
  transaction and balance data.
- **[hostel-management-system](https://github.com/vaishali16-maker/hostel-management-system)** — 
  Hostel management system built in PHP, handling room booking for residents.
